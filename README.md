# Codex Switcher

**Русский** · [English](README.en.md)

**Много аккаунтов. Одна рабочая среда.**

Независимый проект сообщества, не связанный с OpenAI и не одобренный компанией. Ограничения аккаунтов и рабочих пространств продолжают действовать.

Скачайте **CodexSwitcher-1.6-win-x64.zip** в [Releases](https://github.com/kirillromanovv/CodexSwitcher/releases/latest), распакуйте архив и откройте `CodexSwitcher.exe`. Выпуск не подписан; контрольные суммы приложены к релизу. Интерфейс программы сейчас на русском языке.

![Тёмная тема — искусственные аккаунты](docs/images/dark.png)

Локальная программа для Windows 11 x64: расширяемый список карточек «Аккаунт 1, 2, …», ручное переключение аккаунтов ChatGPT в Codex с аккуратным перезапуском приложения.

## Быстрый старт

1. Откройте `CodexSwitcher.exe` из распакованного архива через Проводник. Установка и отдельный .NET не нужны.
2. Нажмите **«Сохранить»** в карточке того аккаунта, который сейчас используется в Codex.
3. В другой карточке нажмите **«Добавить аккаунт»**. На странице входа выберите нужный аккаунт. Если браузер автоматически предлагает первый, выберите другой аккаунт или выйдите из него в браузере. Этот вход добавляется отдельно и не заменяет действующий вход приложения.
4. Завершите активные задачи Codex. Нажмите **«Переключить»** и подтвердите перезапуск. При ошибке запуск программы покажет восстановление.

Закрытие окна скрывает программу в трей. Двойной щелчок по значку открывает окно. В меню значка доступны выбор аккаунта и **«Выход»**. Кнопка **«Выход»** также есть внизу окна. Меню трея показывает почту каждого сохранённого аккаунта и оставшиеся проценты лимитов за 5 часов и неделю. Текущий аккаунт отмечен галочкой; нажмите другой для переключения. Данные обновляются раз в минуту; пункт «Обновить лимиты» запрашивает их сразу. При ошибке обновления сохраняются последние проценты с пометкой «не обновлено». Вход в браузере можно отменить; во время замены авторизации необходимо дождаться завершения операции.

«Войти» обновляет вход того же аккаунта и рабочего пространства. Вход другого аккаунта вместо сохранённого отклоняется. «Сохранить» позволяет заменить карточку текущим входом с подтверждением.

Если аккаунт выбран, но Codex не запустился, откройте Codex через меню «Пуск». Если истекла или отозвана сессия, нажмите «Войти».

## Добавление аккаунтов

При первом запуске видны две карточки. Кнопка «Добавить аккаунт» добавляет следующую пустую карточку; затем нажмите «Войти» или «Сохранить». Фиксированного ограничения в пять аккаунтов больше нет. Список добавленных карточек сохраняется между запусками в `accounts.json`. Существующие защищённые входы, включая аккаунты 3–5, обнаруживаются автоматически; повторный вход не нужен. Новые аккаунты также отображаются в трее и участвуют в обновлении лимитов. Значок корзины рядом с заголовком пустой карточки удаляет её без подтверждения. Удаление сохраняется после перезапуска; можно убрать и обе стартовые карточки, а потом добавить новые. Карточки с любым файлом сохранённого входа, включая повреждённый, эта операция удалить не может. Номера оставшихся аккаунтов сохраняются.

## Светлая и тёмная тема

Значок месяца / солнца находится справа вверху окна. Месяц включает тёмную тему, солнце — светлую. Название действия видно в подсказке и доступно для экранного диктора; текстовый пункт переключения также есть в меню трея. Тема применяется сразу, включая карточки, подсказки и меню трея. Выбор сохраняется для следующего запуска в файле `theme.txt` защищённой папки программы. По умолчанию используется светлая тема.

## Как сохраняются данные

- Чаты, проекты, настройки и скиллы остаются в общей локальной папке Codex. Облачные чаты и доступы зависят от аккаунта. Общая локальная среда означает, что рабочие и личные файлы не изолируются друг от друга.
- Сохранённые входы и журнал восстановления хранятся в `%LOCALAPPDATA%\Codex Switcher` в зашифрованном виде: Windows DPAPI CurrentUser. Права папки ограничены вашим пользователем и SYSTEM. Копирование профиля другому пользователю или на другой компьютер не является способом переноса входа.
- Активный `%USERPROFILE%\.codex\auth.json` сохраняет штатный формат Codex. При заданном `CODEX_HOME` используется эта папка. Активный файл содержит секреты в формате Codex; программы с правами вашего пользователя могут читать его и расшифровывать сохранённые копии.
- Вход и проверка выполняются штатным `codex.exe app-server` из установленного Store-пакета. Пароли принимает браузер. Утилита не запрашивает API-ключи, не отправляет запросы генерации и не расходует платный API.
- Временная папка входа имеет закрытые права и удаляется после завершения/отмены операции. При аварийном завершении там может остаться временный файл авторизации: защищён правами папки, но не DPAPI. Не делитесь папкой хранилища.
- Содержимое токенов, ответы сервера и адрес браузерного входа не записываются в журналы программы. Диагностика и превью используют пустую папку или искусственные данные.

Перед заменой входа программа проверяет выбранный аккаунт, сохраняет обновлённый текущий вход, записывает защищённый журнал и атомарно заменяет только `auth.json`. При сбое восстанавливает прежний вход. Если восстановление не может завершиться, журнал остаётся, а новые операции заблокированы. Если другая программа успела выбрать третий аккаунт, автоматическое восстановление остановится, чтобы не затереть его.

## Совместимость и ограничения

Требуется установленный **Codex из Microsoft Store**, пакет `OpenAI.Codex`. Программа заново находит пакет при операции, учитывая обновление Store. Проверена установка `26.930.7945.0`, протокол `codex-cli 0.160.1`.

Эта версия работает с обычным файловым входом ChatGPT (`auth.json`). API-ключи, внешние токены, системное хранилище `keyring/auto`, память `ephemeral`, нестандартные серверы входа и сложные настройки входа внутри профилей не поддерживаются: программа останавливается и не меняет конфигурацию. Ограничения аккаунта/рабочего пространства не обходятся. Системные политики дополнительно применяет штатный Codex.

Завершение выполняется запросом Windows Restart Manager к главному процессу, проверенному по полному пути Store-пакета, PID и времени запуска. Это завершает приложение и при скрытом окне в трее. Флаг принудительного завершения не используется. Если Codex отказывается завершаться, переключение останавливается; выберите «Выход» в меню или трее Codex. Дополнительно программа ждёт окончания дочерних процессов до 30 секунд. При других активных сессиях Codex CLI/расширения переключение блокируется. Изменения входа повлияют и на другие инструменты, использующие ту же папку Codex.

Нет автозапуска, автообновлений и автоматического выбора аккаунта.

## Лимиты и подписка

Для каждого сохранённого аккаунта программа запрашивает лимиты через штатный `account/rateLimits/read` в отдельной защищённой временной папке. Обновление выполняется раз в минуту, включая работу в трее; кнопка «Обновить» запрашивает данные сразу. Запросы выполняются последовательно, не пересекаются с переключением или входом и не расходуют запросы генерации.

Показаны остаток в процентах для окон 5 часов и недели, дата и обратный отсчёт до их обновления, тариф, время получения данных и число доступных сбросов. При ошибке последние полученные данные помечаются как не обновлённые. Непредоставленные значения показываются как «нет данных» или «—», а не как нулевой остаток. Используются фактические длительности окон сервера: окно другой длительности не выдаётся за пятичасовое. Число сбросов берётся из `availableCount`; программа не использует сбросы и не покупает кредиты. Для каждого предоставленного сброса показаны дата и время истечения; ближайшие идут первыми. При наведении доступны дата получения и оставшееся время. Если сервер не предоставляет сроки всех сбросов, недостающие данные явно обозначаются. Сброс без ограничения срока показан отдельно.

**Дата продления подписки указывается вручную** через календарь: текущий протокол Codex её не возвращает. Поле имеет пометку «вручную», хранится в зашифрованной карточке и сохраняется при переключении/повторном входе. Очистите календарь для удаления даты. Дата обновления лимита и продление подписки — разные поля.

Старые карточки автоматически отображаются как «Аккаунт 1» и «Аккаунт 2». Их защищённые файлы остаются совместимыми; повторный вход для переименования не нужен.

## Обновление со старой версии

Выберите «Выход» в трее **Codex Switcher**, затем запустите обновлённый ярлык или EXE из нового архива. Старый переключатель продолжает работать, если только закрыть его окно крестиком. Оба выпуска используют одно защищённое хранилище, поэтому одновременно запускать их нельзя.

## Что проверено

45 автоматических проверок используют искусственные токены и локальный тестовый сервер. Проверены шифрование/повреждение профиля, переключение в обе стороны, обновление текущего входа, отказ закрытия, откат, восстановление после сбоя, чужое изменение входа, ограничения рабочего пространства, необычная запись защищённых настроек, отказ записи при откате и последующее восстановление, честный статус запуска уже выбранного аккаунта, отмена запроса, раннее уведомление о входе и отсутствие серверного текста с секретами в ошибках. Отдельно проверен штатный протокол в пустой папке без входа и отрисовка окна с тестовыми адресами.

Дополнительные проверки: чтение лимитов через тестовый сервер и удаление временного файла входа; пять карточек с совместимостью старых файлов; сохранение ручной даты подписки; завершение скрытого тестового приложения через Restart Manager, сохранение его состояния и отсутствие воздействия на другое приложение; корректный отказ от завершения.

Локальная проверка чтения лимитов и сроков сбросов на сохранённых аккаунтах прошла успешно; активный `auth.json` остался без изменений. В одном ответе пятичасовое окно не было предоставлено; программа показывает «нет данных». Пользователь подтвердил работу переключения версии 1.0. **Новое завершение настоящего Codex и переключение версии 1.1 ещё требуют ручной проверки после завершения активных задач.** Во время разработки работающий Codex не закрывался. В версии 1.2 дополнительно проверены сроки сбросов, отсутствие срока, непредоставленные данные, фильтрация использованных сбросов и дубликатов. Новый интерфейс проверен в обычном и узком окне. Версия 1.5 дополнительно проверена на добавлении 12 карточек с сохранением после перезапуска, обнаружении старых файлов и переключении между аккаунтами с номерами больше пяти.

## Сборка исходников

Проект C# / WPF, .NET 10, без сторонних библиотек. Скрипты используют локальный SDK `.tools/dotnet`, если он есть, иначе установленный `dotnet`. Для первой самостоятельной сборки нужен SDK 10.x и доступ к официальному NuGet для компонентов переносимой версии.

```powershell
./scripts/verify.ps1 -ProtocolSmoke -Preview
./scripts/build.ps1
```

`verify.ps1` не запускает реальный вход и не переключает аккаунты. `-ProtocolSmoke` читает Store-пакет и запускает `initialize`/`account/read` в новой пустой папке проекта. `-Preview` создаёт изображения с искусственными адресами. Скрипт останавливается при любой ошибке проверки.

Основные исходники: `src/CodexSwitcher.Core`, `src/CodexSwitcher.App`; тесты: `tests/CodexSwitcher.Tests`.

Официальные источники: [протокол app-server](https://learn.chatgpt.com/docs/app-server), [вход и хранилище Codex](https://learn.chatgpt.com/docs/auth), [Windows DPAPI](https://learn.microsoft.com/en-us/windows/win32/api/dpapi/nf-dpapi-cryptprotectdata), [атомарная замена файла Windows](https://learn.microsoft.com/en-us/windows/win32/api/winbase/nf-winbase-replacefilew).
